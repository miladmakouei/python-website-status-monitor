# Website Status Monitor

یک ابزار ساده با Python برای بررسی وضعیت دسترسی وب‌سایت‌ها و اندازه‌گیری زمان پاسخ‌گویی آن‌ها.

در این پروژه می‌توان چند آدرس اینترنتی را وارد کرد تا برنامه وضعیت هرکدام را بررسی کرده و نتیجه را به‌صورت جداگانه نمایش دهد.

## امکانات

- بررسی چند وب‌سایت در یک اجرا
- نمایش HTTP Status Code
- اندازه‌گیری زمان پاسخ‌گویی
- تشخیص خطاهای HTTP و اتصال
- تعیین محدودیت زمانی برای دریافت پاسخ
- نمایش خلاصه وضعیت وب‌سایت‌ها

## تکنولوژی‌های استفاده‌شده

- Python 3
- `urllib.request`
- `urllib.error`
- `time`
- List و Dictionary
- Functions
- `try/except`

## پیش‌نیازها

- نصب Python 3
- اتصال به اینترنت

برنامه فقط از کتابخانه‌های داخلی Python استفاده می‌کند و به نصب پکیج خارجی نیاز ندارد.

## نحوه اجرا

دریافت پروژه:

```bash
git clone https://github.com/USERNAME/python-website-status-monitor.git
```

ورود به پوشه:

```bash
cd python-website-status-monitor
```

اجرای برنامه:

```bash
python3 main.py
```

## نکته درباره نتایج

این برنامه یک بررسی ساده از دسترسی HTTP انجام می‌دهد. دریافت کدهایی مانند 403 یا 404 به معنی پاسخ‌گویی سرور است، اما الزاماً به معنی سالم بودن صفحه یا سرویس موردنظر نیست.

این ابزار جایگزین سیستم‌های حرفه‌ای مانیتورینگ زیرساخت نیست و در این نسخه بررسی‌ها فقط هنگام اجرای برنامه انجام می‌شوند.
